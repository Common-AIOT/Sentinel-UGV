# Protocol

제어, 텔레메트리, 임무 상태, 탐지 이벤트와 미디어 메타데이터의 통신 규약을 보관합니다.

모든 메시지는 `timestamp`, 발신 주체 식별자와 메시지/임무 식별자를 포함해야 합니다. 수동 제어 명령에는 TTL과 제어권 토큰을 포함하고, 만료된 명령은 실행하지 않습니다.

채널별 책임, 제어권, 재연결과 미디어 업로드 흐름은 [제어와 텔레메트리 문서](../../docs/architecture/control-and-telemetry.md)를 기준으로 합니다. 구체 필드는 `schemas/`의 버전된 계약이 이 문서보다 우선합니다.
