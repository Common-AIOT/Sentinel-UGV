# 50. STT·LLM·TTS 모델 테스트

> Jira: S15P11A301-50 · 상태: 완료
> 선행: [모델 조사(S15P11A301-49)](49-STT-LLM-TTS-모델-조사.md) · 후속: 파이프라인 구현(S15P11A301-69)

[조사 단계](49-STT-LLM-TTS-모델-조사.md)에서 선정한 후보를 개발 PC에서 실측해 모델을 확정한 기록입니다.
젯슨 실측(구현 단계)에서 RAM·지연·비전 동시구동 FPS를 재측정하기 전, **정확도·안정성 기준으로 조합을 좁히는 것**이 목적입니다.

## 50-1. 테스트 환경

| 항목 | 값 |
|---|---|
| 장비 | 개발 PC (x86, NVIDIA RTX 4070) |
| STT | faster-whisper, device=cuda, compute=float16 |
| LLM | Ollama (qwen2.5:1.5b/3b, qwen3-1.7b-q8, exaone3.5:2.4b) |
| TTS | MeloTTS(KR) |
| 오디오 | 16kHz mono float32 통일 |

> 개발 PC는 float16으로 측정했다. 젯슨은 메모리 제약으로 **int8**을 사용하며, 지연·정확도는 구현 단계에서 재측정한다.

## 50-2. 테스트 구성

| 스크립트 | 내용 |
|---|---|
| 녹음/노이즈합성 | clean 발화 녹음 + 모터소음을 SNR 10/5/0/-5로 합성 |
| SED 테스트 | YAMNet 사람소리 탐지(검증부족으로 이후 제외) |
| STT 테스트 | 모델별 WER·지연·no_speech_prob 측정 |
| LLM 테스트 | 케이스별 JSON 유효성·매핑·지연 |
| TTS 테스트 | 안내 문구 생성 품질·지연 |
| 파이프라인 벤치 | STT 1회 캐싱 + LLM 다회차 반복 → 지연·등급 일관성 집계 |

측정 원본은 코드 저장소의 `ai/stt/bench/`로 재현 가능하며, CSV 산출물(`results/*.csv`)은 커밋하지 않는다(가중치·데이터와 함께 `.gitignore`).

## 50-3. 데이터셋

- **clean**: 구조요청/부상/환경위험 발화(예: "다리가 무언가에 깔렸어요 움직일 수가 없어요", "가스 냄새가 너무 심하게 나요"), 침묵 파일.
- **mixed**: 위 발화에 모터소음을 SNR 10/5/0/-5로 합성해 저SNR 강건성 측정.
- STT 정답지(`ground_truth.json`)로 WER 자동 채점, 침묵/노이즈 파일은 "헛소리(환각) 여부"만 확인.

## 50-4. 결과 요약

| 항목 | 결과 | 판정 |
|---|---|---|
| STT 지연 | small, GPU 기준 240~560ms | ✅ 실용 |
| LLM 지연 | 후보 모델 유사, ~1.1초 | ✅ 실용 |
| LLM JSON 안정성 | qwen2.5:3b 다회차 일관성 100% + 부상 triage 정확 | ✅ 확정 |
| 저SNR 안전가드 | 반복환각·빈출력·무음 → 적색(중증)으로 안전 처리 | ✅ 성공 |
| 침묵 처리 | 근-침묵 잔향에서 STT 환각 우회 관측 | ❌ 개선 필요 |
| SED | 순수노이즈/비언어소리 검증 부족 | ⚠️ 시나리오 제외 |

- **WER의 SNR별 상세 수치**는 `results/stt.csv`로 재현한다(모델 클수록 정확하나 느림, 정확도-속도 트레이드오프 확인).
- LLM은 **"무응답+신음감지" 케이스를 consciousness="무반응"으로 매핑**하고, 진단("중상입니다")으로 넘어가지 않고 사실만 추출함을 확인.

## 50-5. 확정 사항

| 단계 | 확정 | 근거 |
|---|---|---|
| VAD | Silero VAD | 노이즈 1차 컷, torch 경량 |
| STT | **faster-whisper `small`** | 저SNR·약한발화 강건성, 지연 240~560ms |
| LLM | **`qwen2.5:3b`** | 다회차 일관성 100% + triage 정확 |
| TTS | MeloTTS(KR) + 정형문구 사전녹음 | 동적/정형 혼용으로 자원 절약 |
| 등급 | 규칙 기반 triage | LLM 자유판단 배제, 재현·설명 가능 |

### 안전 가드(확정)

- `is_valid_stt`: 빈 출력 / no_speech_prob>0.7 / 반복 환각 / 프롬프트 복사를 무효 처리.
- `strip_hallucinated`: 발화에 없는 부위·위험요소 제거.
- `coerce_defaults`: enum 밖 값·타입 오류를 안전값(미확인/빈배열/0)으로 보정.
- `triage_rule`: 무반응·통증반응·신음만·불가 → 적색, 혼미·이동불가·단어만 → 황색, 명료·이동가능 → 녹색.

## 50-6. 결정 및 범위 변경

1. **SED 제외** — 순수 모터소음/비언어 소리 검증 부담이 크고 시연 핵심이 아니므로 시나리오에서 뺀다. 트리거는 **비전(객체탐지)** 이 기본이며, "무응답=중증" 보고 경로는 유지한다.
2. **명세(33장) 대비 확장** — 33장은 초기값으로 base급 STT + 규칙 기반 키워드 파싱을 제시한다. 실측 결과 **small + LLM(qwen2.5:3b) 정보 구조화**가 저SNR·자유발화에서 더 안정적이어서 이를 채택한다. 규칙 기반 축소안은 젯슨 자원 부족 시 fallback으로 유지한다(문서 유지 원칙: 차이를 근거와 함께 기록).

## 50-7. 알려진 이슈

- **근-침묵 환각**: 완전 무음이 아닌 매우 작은 잔향에서 STT가 헛단어를 뱉는 우회 경로 관측. 현재 원본 RMS 게이트 + `is_valid_stt`로 방어하나 완전하지 않다.
  개선 방향: 블록리스트 + 침묵 재녹음 재측정 + STT 프롬프트에서 특정 단어 제거.
