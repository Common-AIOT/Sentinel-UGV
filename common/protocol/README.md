# Protocol

제어, 텔레메트리, 임무 상태, 탐지 이벤트와 미디어 메타데이터의 통신 규약을 보관합니다.

공통 MQTT 메시지는 `common/schemas`의 envelope·mission·state·telemetry 계약을 따릅니다.
메시지 종류에 따라 `timestamp`, 발신 주체와 임무/명령 식별자를 포함합니다.

관제 웹의 명령은 백엔드 Control Session과 STOMP 경로를 사용합니다. 실제 수동 주행은
현재 모바일 브라우저가 모터 ESP32에 직접 연결하는 별도 경로이며, 보드의 `sid`, deadman,
250ms TTL로 제한됩니다. 이 경로에는 백엔드 제어권 토큰이 전달되지 않으므로 두 계약을
같은 것으로 문서화하면 안 됩니다.

채널별 책임, 제어권, 재연결과 미디어 업로드 흐름은 [통합 명세서](../../docs/README.md), 특히 [05-통신-서버-영상.md](../../docs/05-통신-서버-영상.md)를 기준으로 합니다. 구체 필드는 `schemas/`의 버전된 계약이 이 문서보다 우선합니다.
