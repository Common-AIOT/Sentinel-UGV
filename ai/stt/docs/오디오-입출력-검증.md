# BRIO 100 마이크·블루투스 스피커 입출력 검증

> Jira: S15P11A301-111
>
> 대상: Jetson Orin Nano 8GB, Logitech BRIO 100 내장 마이크, 블루투스 스피커
>
> 목적: 음성 세션 투입 전에 장치 선택·녹음·재생·재연결·카메라 동시 사용을 증적으로 확인한다.
>
> 용어: [`음성-파이프라인-용어집.md`](음성-파이프라인-용어집.md)

이 문서의 명령은 저장소 루트의 `.venv`가 활성화된 Jetson에서 실행한다. 장치명과
실측값은 제품·Bluetooth 어댑터·PipeWire/PulseAudio 설정에 따라 달라질 수 있으므로
예시 값을 결과로 복사하지 않는다.

## 1. 사전 조건

```bash
cd ~/projects/S15P11A301
source .venv/bin/activate
cd ai/stt

python -c "import sounddevice, soundfile; print('audio packages OK')"
command -v pactl
command -v v4l2-ctl
```

`pactl` 또는 `v4l2-ctl`이 없다면:

```bash
sudo apt update
sudo apt install -y pulseaudio-utils v4l-utils
```

## 2. Bluetooth 출력 프로필 고정

BRIO 100의 USB 마이크를 입력으로 사용하므로 Bluetooth 스피커는 통화용
HFP/HSP가 아닌 **A2DP 출력 프로필**을 사용한다.

```bash
pactl list short cards
pactl list short sinks
pactl info | grep 'Default Sink'
```

설정 화면에서 스피커를 페어링한 뒤 `pactl list cards`의 `Active Profile`이
`a2dp-sink` 계열인지 확인한다. 스피커 이름은 다음 단계의 `--output-match`에
사용하므로 그대로 기록한다.

## 3. 장치 탐색과 16kHz mono 호환성 확인

먼저 목록만 출력한다. 이 명령은 녹음·재생하지 않는다.

```bash
python -m tools.check_audio_io
```

통과 조건:

- 선택된 입력 장치 이름에 `BRIO`가 포함된다.
- `mono / float32 / 16000Hz` 입력 설정이 `[OK]`로 표시된다.
- `~/audio_io_report.json`에 장치 목록과 선택 결과가 저장된다.

BRIO 이름이 다르거나 여러 개면 실제 목록에 맞춰 더 구체적으로 지정한다.

```bash
python -m tools.check_audio_io --input-match "BRIO 100"
```

## 4. 녹음·재생 시험

아래 `<스피커 장치명>`은 2~3단계에서 확인한 실제 이름 일부로 바꾼다.

```bash
python -m tools.check_audio_io \
  --input-match "BRIO" \
  --output-match "<스피커 장치명>" \
  --record-seconds 10 \
  --playback \
  --wav ~/audio_io_sample.wav \
  --report ~/audio_io_report.json \
  2>&1 | tee ~/audio_io_console.log
```

통과 조건:

- BRIO 입력과 Bluetooth 출력이 각각 하나로 선택된다.
- 녹음·재생 과정에 `[FAIL]`, underrun, 장치 연결 해제 오류가 없다.
- 사람이 말한 구간의 `peak_dbfs`가 `-3dBFS`보다 작아 clipping이 없고,
  `clipped_ratio`가 `0`이다.
- WAV를 다시 들었을 때 음성이 식별 가능하며 과도한 끊김·왜곡이 없다.

RMS는 환경 소음과 발화 거리에 따라 달라지므로 이번 업무에서는 절대 합격선으로 쓰지 않고
비교 기준으로 기록한다.

## 5. BRIO 카메라·마이크 동시 사용

터미널 A에서 카메라 스트림을 시작한다.

```bash
v4l2-ctl --list-devices
v4l2-ctl --device=/dev/video0 \
  --stream-mmap=3 --stream-count=300 --stream-to=/dev/null
```

카메라가 실행 중인 동안 터미널 B에서 4장의 녹음·재생 명령을 다시 실행한다.

통과 조건:

- 카메라 300 frame 수집과 10초 녹음이 모두 오류 없이 끝난다.
- 동시 실행 전후 오디오 장치 index와 이름이 유지된다.
- 녹음에 주기적 끊김이나 USB 연결 해제가 없다.

`/dev/video0`이 BRIO가 아니면 `v4l2-ctl --list-devices` 결과의 BRIO 경로로 바꾼다.
장기적으로는 번호가 아닌 udev 별칭을 사용해야 한다.

## 6. Bluetooth 재연결·첫 재생 시험

다음 절차를 3회 반복한다.

1. 스피커 전원을 끈다.
2. `pactl list short sinks`에서 장치가 사라지는지 확인한다.
3. 스피커 전원을 켜고 자동 재연결까지 걸린 시간을 초시계로 잰다.
4. `pactl info`의 기본 sink가 해당 스피커인지 확인한다.
5. 4장의 명령을 실행하고 재생 시작까지 체감 지연과 첫 음절 누락 여부를 기록한다.

자동 재연결이 되더라도 기본 sink가 다른 장치로 바뀌면 실패다. 첫 음절이 반복해서 잘리면
운영 시 안내 음성 앞에 짧은 무음 프리롤을 추가하는 후속 업무로 등록한다.
