# 오디오 입출력 검증 도구

> Jira: S15P11A301-111
>
> 대상 코드: `tools/check_audio_io.py`

## 1. 목적

Logitech BRIO 100 내장 마이크와 Bluetooth 스피커의 입출력 상태를 같은 방식으로
점검하고, 장치 정보와 녹음 레벨을 JSON 증적으로 저장하기 위한 도구다.

이 문서는 검증 결과를 기록한 문서가 아니다. 실제 합격 여부는 장비를 연결한 환경에서
도구를 실행한 뒤 [`오디오-입출력-검증.md`](오디오-입출력-검증.md)의 기준으로 판정한다.

## 2. 검증 대상

도구는 다음 항목을 확인할 수 있도록 작성했다.

| 대상 | 확인 내용 |
|---|---|
| 입력 장치 탐색 | 지정한 문자열과 일치하는 입력 장치 이름·index·채널 수 |
| 출력 장치 탐색 | 지정한 문자열과 일치하는 출력 장치 이름·index·채널 수 |
| 입력 형식 | mono, float32, 16kHz 사용 가능 여부 |
| 출력 형식 | mono, float32, 16kHz 사용 가능 여부 |
| 마이크 녹음 | 지정 시간 동안 녹음하고 PCM WAV로 저장 |
| 스피커 재생 | 녹음 결과를 선택한 출력 장치로 재생 |
| 녹음 레벨 | RMS, RMS dBFS, peak, peak dBFS |
| clipping | 절댓값 0.99 이상인 sample 비율 |
| 재현 정보 | 실행 시각, Git commit, 플랫폼, 전체 장치 목록 |

## 3. 기본 사용법

`ai/stt`에서 실행한다.

```bash
python -m tools.check_audio_io
```

기본 입력 검색 문자열은 `BRIO`다. Bluetooth 출력까지 선택하려면 실제 장치명 일부를
지정한다.

```bash
python -m tools.check_audio_io \
  --input-match "BRIO" \
  --output-match "<스피커 장치명>"
```

10초 녹음 후 같은 샘플을 재생하고 증적을 저장하는 예시는 다음과 같다.

```bash
python -m tools.check_audio_io \
  --input-match "BRIO" \
  --output-match "<스피커 장치명>" \
  --record-seconds 10 \
  --playback \
  --wav ~/audio_io_sample.wav \
  --report ~/audio_io_report.json
```

## 4. 산출물

| 산출물 | 내용 |
|---|---|
| `audio_io_sample.wav` | 마이크로 녹음한 16kHz mono PCM 음성 |
| `audio_io_report.json` | 장치·환경·녹음 레벨 수치 |
| 콘솔 출력 | 선택된 장치와 단계별 성공·실패 메시지 |

JSON에는 다음과 같은 구조로 결과가 기록된다.

```json
{
  "timestamp_utc": "...",
  "git_commit": "...",
  "platform": "...",
  "sample_rate_hz": 16000,
  "selected_input": {},
  "selected_output": {},
  "recording": {
    "duration_seconds": 10,
    "wav_path": "...",
    "rms_dbfs": 0,
    "peak_dbfs": 0,
    "clipped_ratio": 0
  }
}
```

위 숫자는 스키마 예시이며 실제 측정 결과가 아니다.

## 5. 도구가 자동 판정하지 않는 항목

다음 항목은 사람이 직접 듣거나 별도 절차를 수행해야 한다.

- 녹음된 발화의 식별 가능 여부
- 첫 음절 누락
- 체감 재생 지연
- Bluetooth 전원 재연결 시간
- 재연결 후 기본 sink 복구
- BRIO 카메라와 마이크의 동시 사용 안정성
- Jetson 통합 환경의 최종 PASS/FAIL

해당 절차와 완료 기준은
[`오디오-입출력-검증.md`](오디오-입출력-검증.md)를 따른다.
